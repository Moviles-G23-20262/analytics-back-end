Insights

    How this is calculated

    • A listing counts as dead when its status is still AVAILABLE (not sold or reserved) and its age at query time meets or exceeds the selected stale threshold (default 14 days).
    • Time active for unsold listings is measured from Material.createdAt to now; for sold listings it uses completed exchange time so both cohorts are comparable.
    • The survival curve uses the right-censored Kaplan-Meier estimator so recently created fresh listings do not bias longer horizons.
    • Each dead listing is described by four standardized signals — price ratio vs. category median, number of photos, seller rating, and days active — and grouped via deterministic K-Means (up to 4 clusters).
    • Sellers can review per-listing risk alerts and apply suggested price drops in the mobile app's Listing Health Advisor view.
