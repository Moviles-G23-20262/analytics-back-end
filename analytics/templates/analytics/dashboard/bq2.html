Insights

    How this is calculated

    • A view is a LISTING_VIEW analytics event. Only distinct listings count, so re-opening the same listing does not add to the number.
    • Before contact cuts each buyer's views at their first CONTACT_SELLER event. Before exchange cuts at the buyer's first completed exchange.
    • Views are counted up to and including the cut. Buyers with no views before the cut count as 0, which pulls the averages down.
    • Both steps analyse different groups of users, so the second is not necessarily a subset of the first.
