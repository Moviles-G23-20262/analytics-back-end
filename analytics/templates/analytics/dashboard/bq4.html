    How this is calculated

    • A conversation is a chat room. It agrees on a meeting point when a MEETING_CONFIRMED event exists for it. If that event type is not recorded yet, a completed exchange with a meeting point between the same buyer, seller and listing is used instead.
    • Messages are counted from the first message up to the agreement time. Time is measured from the first message to the agreement.
    • Conversations that never agreed are reported separately and excluded from the message and time statistics.
    • When the fallback is used, the agreement time is the exchange completion time, which can be later than the real agreement. In that case the times above are an upper bound.
